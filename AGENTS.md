# Project Rules

## Git workflow (bắt buộc)

- Repo luôn dùng: `https://github.com/TS205312/Demo-dashboard-1.git` (remote name: `Thinhdev`)
- KHÔNG push thẳng lên `master` (không có quyền / không được phép).
- Mọi thay đổi: commit + push lên branch `blackboxai/command-center-redesign`, sau đó tạo Pull Request (via `gh pr create`) để user merge trên trang Pull requests.
- Chỉ commit khi user yêu cầu ("pull đi" / "push đi" / "commit" = yêu cầu push lên branch feature + tạo PR).
